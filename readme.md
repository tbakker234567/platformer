# The Stolen Sun

## About the Game

The sun has been stolen by an evil wizard pirate, plunging the kingdom into darkness.

Play as Guy, a former apprentice, as he journeys through the floating islands of the Windward Crown to retrieve a powerful magical staff and reclaim the stolen sun.

## Controls

* Move left: A / Left Arrow
* Move right: D / Right Arrow
* Jump: Space
* Use weapon: Left Mouse Button
